# Резервна копія нормалей каменю й піску

Конверсія виконана 17 жовтня 2026 року за запитом користувача.

Непрозорі нормалі Stone (ID 2) і Sand (ID 3) повернуті на 45° угору у локальному базисі атласу:

`x' = x; y' = (y + z) / sqrt(2); z' = (z - y) / sqrt(2)`.

Оновлено лише NormalPixels цих блоків у чернетці й прямокутники (128,0,64,48), (192,0,64,48) ігрового normal-атласу (PNG, координати від верхнього лівого кута). Прозорі пікселі, кольорові текстури та решта блоків не змінювались.

Для відновлення, закривши редактор малювання:

- `BlockAtlasDraft.asset.bak` скопіювати в `Assets/Tools/BlockAtlasEditor/Editor/BlockAtlasDraft.asset`.
- `BlockAtlas_Normal.png.bak` скопіювати в `Assets/Art/World/BlockAtlas_Normal.png`.

Відновлювати обидва файли разом. Копії містять повний стан файлів на момент конверсії, тому відновлення також скасує пізніші зміни в них. Конвертер у Tools/BlockAtlasEditor/Editor відмовляється працювати повторно за наявності цих резервних копій, щоб уникнути подвійного повороту.
