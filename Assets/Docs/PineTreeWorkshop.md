# Pine tree blockout workshop

Open **Tools → Game → Pine Tree Workshop**. This editor-only tool generates a deterministic
3D Scots-pine blockout, not a billboard or final pixel-art asset. No scene/world content changes.
Adjust seed, height, trunk radius, crown spread, crown start and branch count.
Foliage is now made of tapered planar needle ribbons, paired along three short shoots at each terminal spray,
not solid ellipsoids. Needle pairs and ribbon half-width control density/readability at sprite resolution.
Cards are viewed two-sided in the rasterizer with camera-facing normal signs. When rendering the exported
OBJ in a 3D application, enable a two-sided material; OBJ itself does not encode material culling settings.
Use Silhouette first to judge proportions. A 1.9-world-block ruler indicates player scale.
Color is flat reference shading; Normals shows linear sprite-space encoded normals.

All four views share one frame size, pixels-per-unit and base pivot. Projection uses the game's
screenX=right and screenY=worldY−toward/2 mapping (a shear, not a generic perspective screenshot).
Export selects an empty folder outside Assets and writes four color PNGs, four normal PNGs, four unlit diffuse PNGs,
an OBJ model, settings and pivot/projection notes. It never overwrites an existing nonempty folder.
The exported mesh is a modeling reference. Colors are not clean runtime albedo; repaint before integration.
Rasterization is editor-only and CPU-based; no runtime rendering or ECS/world generation is added.

Real references: Forestry England Scots pine identification and Trees for Life Scots pine forms.
The prototype focuses on tall forest proportions, taper, dead lower limbs and irregular needle sprays.
Trunk/woody branches now receive procedural bark plates and fissures. One periodic world-space height function
drives both diffuse contrast and normal relief, keeping all four views consistent; foliage is excluded.
Adjust Bark detail strength/scale. Diffuse is unlit; Color blockout includes reference directional shading.
The OBJ contains only base geometry, not baked bark textures: surface detail is generated by the sprite rasterizer.
Coastal wind deformation, growth, collision, branch/resin resources and gameplay are not implemented.
