# Flint / Ignite prototype

Build spawn fix: CoastalItemSpawnSystem resolves Flint ID 4 and Pyrite ID 7 directly from baked ItemDefinitionReference instead of comparing Resources.Load objects by Unity instance identity. Both definitions and world sprites must be available before the shared ledger records a completed pass. One-time [CoastalItemSpawn] warnings identify missing/duplicate libraries, missing definitions/sprites, absent chunks or incomplete buffers; the first nonempty successful spawn is logged once. Repeated frames do not repeat these messages. Existing saves/ledger, density and sleep behavior remain unchanged. Runtime compilation and spawn/asset checks pass; a newly built player still requires end-to-end verification.

Impact threshold: collision context now includes normal approach speed max(0, -dot(velocityAtContact, normal)); tangential motion does not count. Velocity is evaluated at the swept hit fraction before collision response, not at the end of the substep. Block Is condition exposes MinImpactSpeed (default 0 for other graphs). Flint Stone condition starts at 10.5. With Throw's time .65, gravity 30, source height 1.2 and radius .04, a same-base table top at height 1 has about 10 normal speed versus 11.53 at floor height 0. This is trajectory math, not gameplay verification; intermediate wall/ceiling hits and changed Throw settings can change the outcome. Sleeping physics is unchanged and threshold evaluation only runs on actual impacts.

Pyrite spawn update: CoastalItemSpawnSystem now also spawns registered Pyrite on the highest sky-exposed Stone surface in RockyShore, with a distinct seeded hash, 1/64 eligible-column probability and at most two per chunk. Top surface height supports full and lower-half stone. No cave/covered/underwater surfaces are eligible. Existing flint density/hash/cap are unchanged. Both species share the persisted processed-chunk ledger; previously processed save chunks are not retroactively reseeded. New chunks receive both species in one pass. Pyrite starts grounded and uses the existing sleep registration; no ongoing collision checks were added.

## Try it

Restart Play mode so the item library rebakes. Flint (item ID 4) spawns on sky-surface sand in Rocky Shore Beach columns of newly processed generated chunks: deterministic seeded 1/32 eligible-column chance, at most three per chunk. Existing saves without a spawn ledger receive the new spawns on first visit; existing debug equipment is unchanged. Empty a hand with Throw and use the existing Pick skill to collect flints. Hold one in each hand, throw an unlit Torch onto reachable ground, and use Ignite on its Top cell. Pick distance is shared directly: `Configs/PickUpDistance.asset`, currently 2 world units.

## Persistence

World items already serialize their mutable instances. An optional CoastalItemChunks array additionally stores chunks whose spawn pass completed, including empty passes. It is restored into CoastalItemSpawnedChunk on the item library and imported into the spawner's visited set. Thus picking up flint, revisiting unloaded chunks and reloading the world cannot normally reroll the same chunk. Old saves omit this additive field and remain readable.
